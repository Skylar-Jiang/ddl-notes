# DDL Notes

Windows 11 上的轻量桌面便签：平时安静显示待办，临近截止时再提醒你。

界面沿用 Sticky Notes 的小窗口形态：淡紫底色、柔和圆角、五种低饱和糖果色任务框。支持中文、浅色 / 深色，无需便签账号或服务器，手动任务和提醒可离线运行。Python 3.11+ / Tkinter，只有托盘使用 pystray 和 Pillow。

任务框颜色由系统按当前列表顺序自动轮换，相邻任务颜色不同；新增、排序或展开已完成任务后都会自动调整，无须手动选色。

## 直接运行

源码仓库不包含构建产物；首次从 GitHub 克隆后，请按下文“测试与打包”生成 `dist` 目录。

双击 **`dist\DDLNotes.exe`**，无需安装 Python。默认首次启动是空便签，不会自动添加示例任务，也不会默认注册开机启动。

程序默认约 340 × 450 个逻辑像素，适配 Windows DPI 缩放。拖动顶部移动窗口；拖动窗口边缘调整大小；位置、尺寸和任务自动保存。

- **添加 / 编辑**：底部“添加任务”，点击任务名称或任务右侧 `…` 编辑。`Ctrl+N` 添加，`Ctrl+,` 设置，编辑窗口 `Ctrl+Enter` 保存，`Esc` 取消。
- **完成**：点击圆形复选框。底部“已完成”展开已完成任务，可取消勾选。
- **删除**：右键任务 → 删除任务，确认后删除。
- **排序**：默认逾期未完成 → 将截止 → 无截止 → 已完成。顶部 `…` 可以改用创建时间排序。
- **窗口**：图钉切换置顶，折叠按钮只保留顶栏，横线最小化。双击标题也可折叠。
- **托盘**：默认点关闭隐藏到托盘。托盘双击或右键“打开 DDL Notes”恢复，也可再次双击 exe 恢复已有窗口。
- **彻底退出**：顶部 `…` → “退出 DDL Notes”，或托盘右键 → “退出 DDL Notes”。隐藏和最小化期间仍会提醒；彻底退出期间不会运行提醒。
- **设置**：全局提前提醒分钟数、重复提醒、登录启动、关闭行为、45%—100% 透明度、浅 / 深色，以及 JSON 导入导出。

## 截止时间和提醒

任务可以不设截止时间。有截止时间时采用系统**本地日期时间**，精确到分钟；日期填写 `YYYY-MM-DD`，时间填写 `HH:MM`。任务单独设置的提前提醒分钟数优先，留空则使用全局设置（默认 60 分钟）。0 表示只在到期时提醒。

例如截止为 `2026-10-20 20:00`：默认在 19:00 提醒临期，20:00 提醒到期。每个节点只提醒一次。默认不自动重复提醒；可以开启临期重复提醒，默认间隔 30 分钟。到期后只显示逾期状态，不自动持续弹窗。

提醒使用独立的置顶小窗口，不改变主便签的置顶设置，也不主动抢输入焦点。多任务合并到**一个可滚动提醒窗口**。每条可标记完成或稍后 10 / 30 分钟提醒；“知道了”只收起本次提醒。

- 检查间隔 15 秒，实际弹出最多可能延后约 15 秒；剩余时间文字每分钟更新。
- 完成任务立即撤下该任务正在显示的提醒，停止后续提醒。
- 修改截止时间或单独提醒阈值，重新计算该任务的提醒节点；仅修改名称、描述不清除已提醒记录。
- 休眠恢复、重启或系统时间向前变化时，只补发当前最相关节点。例如已经逾期只补发到期提醒，不再补发旧的临期提醒。
- 已提醒记录与稍后提醒时间均持久化。系统时间向后变化不会重新发送已记录的同一节点。
- 稍后提醒期间若到达截止时间，未发送过的到期提醒优先。
- 重新取消完成不会清空已提醒节点；更改截止时间可重新安排提醒。

## 从课程平台导入

新增 Chrome / Edge 课程助手，自动遍历课程读取南开小雅、长江雨课堂的作业和测验。一次连接后，在浏览器助手中点击同步即可，不需要逐门打开课程。手动录入照常保留；重复同步按来源 ID 更新，不覆盖本地备注和手动完成状态。

当前雨课堂仅同步班级名标注 **2026 年秋** 的课程，小雅读取进行中课程。同步时，雨课堂已明确标注为其他学期的班级，其历史导入任务会先备份再清理，包括无截止任务。截止已超过 **48 小时** 的平台任务不再新增，已导入的同类超期任务也会清理；手动任务保留。本学期无截止任务保留，任务可以跨年截止，不按 DDL 年份过滤。

首次连接：浏览器扩展管理页加载 `dist\browser-helper` → 复制扩展 ID → 便签顶部 `…` → “连接 / 同步课程作业…” → 粘贴 ID 并连接。在安装助手的浏览器内登录课程平台。完整步骤、覆盖范围和卸载方式见 [SYNC-SETUP.md](SYNC-SETUP.md)。

**当前是适配验证版**：已验证本地解析、去重、桥接和模拟接口测试，用户已反馈小雅成功、雨课堂开始正常同步。0.1.5 补充清理雨课堂旧学期无截止任务。平台字段变化会导致失败，助手会显示提示。Codex 内置浏览器的登录态无法直接交给独立程序使用。

同步需要网络；主程序仍然是 Python / Tkinter，未引入 Electron 或浏览器内核。配套 `DDLNotesSync.exe` 仅作为浏览器与便签间的一次性 Native Messaging 桥接。

## 开机启动和移动程序

顶部 `…` → 设置 → 勾选“Windows 登录后自动启动” → 保存设置。

使用当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `DDLNotes` 值，无须管理员权限，不使用计划任务。打包后注册 exe 的绝对路径；源码运行时注册项目虚拟环境中的 `pythonw.exe` 与 `run.py` 绝对路径。多个实例同时启动时，仅保留同一数据目录的一个应用实例。

便携程序没有安装器 / 卸载器。**移动或删除程序前，先在设置中关闭自启动**。如果已移动，手动运行新路径一次会更新现有启动项；如果旧程序已删除，可以在新副本所在目录运行：

```powershell
.\dist\DDLNotes.exe --remove-startup
```

不要把临时预览或测试目录注册为正式启动路径。登录自启动会恢复主便签，不强制取得输入焦点。

## 数据、备份与恢复

正式数据目录为 `%LOCALAPPDATA%\DDLNotes\`，与启动工作目录、exe 所在目录、PyInstaller 解包目录无关。

| 文件 | 用途 |
| --- | --- |
| `data.json` | 任务、提醒状态、窗口设置 |
| `data.json.bak` | 上一次成功保存的数据 |
| `data.json.corrupt-*` | 读取损坏主文件时保留的副本 |
| `before-import-*.json` | 替换导入前的完整备份 |
| `before-sync-cleanup-*.json` | 自动清理平台超期任务前的完整备份 |
| `ddl-notes.log` | 错误与生命周期日志；512 KB 滚动，最多 2 个历史文件 |

保存采用同目录临时文件、flush/fsync 与原子替换。主数据损坏时尝试恢复有效备份并提示，不直接丢弃原文件。

建议用设置中的“导出备份”。“导入备份”会验证文件、询问是否替换全部任务，并先备份当前数据；保持当前外观和自启动设置。也可以先彻底退出，再复制整个数据目录以备份 / 恢复。自启动项属于 Windows 注册表，不包含在 JSON 数据中。

## 从源码运行

需要 Windows 的标准 Python 3.11+（已在 3.12.6 实测）和 Tkinter。只在项目虚拟环境安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

独立的样式预览，不影响正式任务或自启动：

```powershell
.\.venv\Scripts\python.exe run.py --demo
```

预览使用 `%TEMP%\DDLNotes-preview\`，包含几条示例任务。需要隔离测试数据时可以传入 `--data-dir <绝对目录>`。这些选项同样适用于 exe。

## 测试与打包

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
powershell -ExecutionPolicy Bypass -File .\build.ps1 -InstallDependencies
```

构建脚本先执行 Python 和浏览器读取器测试，再生成图标、Windows 主程序与同步桥接程序，并复制助手文件夹。构建阶段需要 Node.js（仅用于 JavaScript 测试；可传 `-NodePath <node.exe 路径>`），用户运行程序无需 Node。已有构建依赖时可省略 `-InstallDependencies`；加 `-OneDir` 可生成解包启动更快的目录版（需要保留整个输出目录）。构建不会安装系统 Python 包。

测试包含纯逻辑、临时目录真实读写、实际 Tk 窗口控件和 Windows 用户级注册表测试。注册表测试使用随机专用值，完成后清理，不开关正式 `DDLNotes` 启动项。实际执行结果与未验证项目见 [TESTING.md](TESTING.md)。

## 已知限制与常见问题

- **关闭电脑后还会提醒吗？** 不会；下次运行时按当前任务状态补发。没有 Windows 后台服务。
- **托盘找不到？** 查看任务栏隐藏图标区域。也可以再次启动程序恢复；托盘启动失败时不会把窗口藏进无法找回的状态。
- **通知中心为什么没有记录？** 第一版使用应用内聚合提醒窗口，不使用 Windows 通知中心。锁屏期间不能保证用户看见弹窗，解锁后仍可查看。
- **时间和时区变化？** 截止时间按本地墙上时间存储，修改系统时区后仍按新的本地钟表时间解释；不支持跨时区会议语义。
- **圆角 / 中文？** Windows 11 原生窗口圆角和本地微软雅黑字体；不依赖网络字体。旧系统可能退化为普通窗口边缘。
- **exe 启动较慢？** 单文件需要先解包；可构建 `-OneDir` 目录版。
- **首次启动系统提示？** 当前交付未做代码签名，也没有安装器。不要绕过系统策略；可从源码运行或自行签名分发。
- **长期稳定性？** 已进行自动化和本机交互测试，尚未做数日运行、真实睡眠 / 重启 / 登录以及多屏跨 DPI 切换测试。

参考实现依据：[Python Tkinter 文档](https://docs.python.org/3/library/tkinter.html)、[Microsoft 用户级 Run 启动项说明](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)、[PyInstaller 打包文档](https://pyinstaller.org/en/stable/usage.html)。
