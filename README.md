# DDL Notes

**把待办放在桌面，把截止时间交给提醒。**

DDL Notes 是一个 Windows 桌面便签工具。它有类似 Sticky Notes 的小窗口、柔和圆角和低饱和糖果色任务卡片，可以记录作业、实验、考试，也可以记下生活中的小事。颜色由系统自动安排，相邻任务颜色不同，不需要自己挑选。

手动记事和提醒可离线使用，无需注册账号。需要导入课程作业时，可以选用配套的 Chrome / Edge 助手。

[下载 Windows 版](https://github.com/Skylar-Jiang/ddl-notes/releases/download/v0.1.5/DDLNotes-windows-x64-v0.1.5.zip) · [查看版本与校验文件](https://github.com/Skylar-Jiang/ddl-notes/releases/tag/v0.1.5) · [课程助手配置](SYNC-SETUP.md) · [反馈问题](https://github.com/Skylar-Jiang/ddl-notes/issues)

> 当前版本：**v0.1.5 预发布版**，已在 Windows 11 x64 上验证。课程助手仍在适配验证中，暂不支持所有学校和学期；不使用课程助手也可以完整使用手动待办和提醒。

## 三分钟开始使用

1. 下载上方的 **`DDLNotes-windows-x64-v0.1.5.zip`**。GitHub Releases 中的 `Source code` 是源码，不是可直接运行的程序。
2. 将压缩包**完整解压**到一个准备长期保留的目录，例如 `D:\Apps\DDLNotes`。不要直接在压缩包内运行。
3. 双击 **`DDLNotes.exe`**。无需安装 Python，也无需管理员权限。首次启动是空便签。
4. 点击底部 **“添加任务”**，填写任务名称，按需设置截止日期和时间，然后保存。
5. 保持程序运行：默认提前 **60 分钟**提醒一次，到期再提醒一次。可以在设置中调整。

只需要桌面便签的话，做到这里就可以了。首次启动不会默认开启 Windows 登录自启动。

解压后的文件如下，请保留它们的相对位置：

```text
DDLNotes/
  DDLNotes.exe          双击这个文件，打开便签
  DDLNotesSync.exe      课程同步桥接程序，无需手动打开
  browser-helper/      可选的浏览器课程助手
  README.md
  SYNC-SETUP.md
  TESTING.md
```

程序目前没有代码签名；如果系统阻止运行，请遵循设备的安全策略，也可以选择从源码运行。

## 日常怎么用

| 想做什么 | 操作 |
| --- | --- |
| 新建任务 | 底部“添加任务”，或 `Ctrl+N` |
| 修改任务 | 点击任务名称，或任务右侧 `…` |
| 不设置 DDL | 在编辑窗口取消勾选“设置截止时间” |
| 标记完成 | 点击任务左侧圆形复选框 |
| 查看 / 恢复已完成任务 | 底部“已完成”展开列表，再次点击复选框可恢复 |
| 删除任务 | 右键任务 → “删除任务…” |
| 置顶 / 折叠 | 顶部图钉 / 折叠按钮；双击标题也可以折叠 |
| 移动 / 调整大小 | 拖动顶栏 / 窗口边缘，位置和尺寸自动保存 |
| 打开设置 | 顶部 `…` → 设置，或 `Ctrl+,` |
| 找回隐藏的窗口 | 系统托盘双击图标，或再次打开 `DDLNotes.exe` |
| 彻底退出 | 顶部 `…` → “退出 DDL Notes”，或托盘右键 → 退出 |

默认按“逾期未完成 → 即将截止 → 无截止时间 → 已完成”排序；顶部 `…` 可切换为创建时间排序。设置里还可以调整浅色 / 深色、窗口透明度、提醒和关闭行为。

**关闭按钮默认隐藏到托盘，提醒继续运行。彻底退出、关机期间不会提醒。** 如果希望每次开机都能看到便签，在设置中勾选“Windows 登录后自动启动”。

## 提醒如何工作

- 日期使用 `YYYY-MM-DD`，时间使用 `HH:MM`，按电脑的本地日期时间解释。
- 例如 DDL 是晚上 20:00，默认在 19:00 和 20:00 各提醒一次。任务可单独调整提前量；填 `0` 表示只在到期时提醒。
- 多个任务合并到一个提醒窗口，可以直接完成任务，或选择稍后 10 / 30 分钟提醒。“知道了”只关闭本次提醒。
- 默认不会持续弹窗。可开启临期重复提醒；截止后不再自动重复。
- 休眠恢复或重新启动后，会按当前状态补发相关提醒，不会逐条重放所有错过的节点。

程序约每 15 秒检查一次提醒，可能有约 15 秒延迟。当前使用应用内提醒窗口，不写入 Windows 通知中心；锁屏时不能保证看到提醒。

## 可选：从课程平台导入作业

不用逐条抄写作业名称和 DDL：在自己的浏览器登录平台后，点击课程助手即可读取对应课程。**同步由你手动点击触发，目前没有后台定时同步。**

| 平台 | 当前支持范围 |
| --- | --- |
| 南开小雅 | `nankai.ai-augmented.com` 中进行中的学生课程：作业、练习、考试 |
| 长江雨课堂 | `changjiang.yuketang.cn` 中班级名明确标注 **2026 年秋** 的课程：内容树中的作业、试卷 |

> **雨课堂学期目前固定为 2026 年秋，界面暂不能切换。** 其他学期、其他学校的小雅实例、其他雨课堂域名尚未适配。不要将“同步完成但无任务”直接理解为平台没有作业；请同时核对同步范围。

首次连接只需完成以下步骤：

1. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择下载包中的 **`browser-helper` 文件夹**。
3. 复制“DDL Notes 课程助手”的扩展 ID。
4. 在便签顶部 `…` → **“连接 / 同步课程作业…”**，粘贴 ID，点击“连接助手”。
5. 在**安装助手的同一个浏览器**里登录课程平台，刷新平台网页，再点击浏览器工具栏的助手 → 同步。

登录凭证只在浏览器中用于访问原平台，本地便签接收作业信息，不接收平台密码或 Cookie。使用便签无需第三方云服务。

同步会按任务来源去重，更新名称、DDL 和平台完成状态，保留本地备注和手动完成状态。请提前了解以下清理规则：

- 距截止时间**超过 48 小时**的平台任务不再新增；已导入的同类超期任务会清理。
- 雨课堂中明确标注为其他学期的班级，已导入任务也会清理，**包括没有截止时间的任务**。
- 手动录入的任务保留。本学期无截止任务保留；本学期任务的 DDL 可以跨到下一年。
- 清理前保存完整备份；备份失败则停止本批同步。读取失败时，不发送部分任务来清理本地清单。

详细安装、更新、覆盖范围、卸载和故障说明见 **[课程同步指南](SYNC-SETUP.md)**。平台接口可能变化，归档课程及部分旧版试卷尚未覆盖，重要 DDL 请与平台核对。

## 数据在哪里？怎么备份？

数据保存在当前 Windows 用户的 **`%LOCALAPPDATA%\DDLNotes\`**，不在程序目录中。你可以在设置里点“打开数据目录”。

| 文件 | 内容 |
| --- | --- |
| `data.json` | 任务、提醒状态和窗口设置 |
| `data.json.bak` | 上一次成功保存的数据 |
| `before-sync-cleanup-*.json` | 课程同步清理前的完整备份 |
| `before-import-*.json` | 替换导入前的完整备份 |
| `ddl-notes.log` | 排查运行问题的日志 |

**日常备份：** 设置 → “导出备份”。恢复时选择“导入备份”；这会替换全部任务，程序会先询问并备份原有数据，当前外观与自启动设置保留。

**更新程序：** 先导出备份并彻底退出便签，再将新版压缩包解压、覆盖原程序目录中的文件。任务数据保存在上述独立目录。课程助手还需要在扩展管理页重新加载，并刷新平台网页。

**移动 / 卸载：** 先关闭自启动，再彻底退出程序。移动后重新设置自启动；使用课程助手时，也需要重新连接助手。删除程序目录不会删除上述任务数据。

## 常见问题

**点了关闭，怎么还有提醒？** 默认只是隐藏到系统托盘。需要完全停止时，请通过菜单选择“退出 DDL Notes”。

**程序已经运行，怎么找不到窗口？** 查看任务栏右下角隐藏图标区域，或再次双击 `DDLNotes.exe` 恢复窗口。同一数据目录只运行一个实例。

**开机后会自动打开吗？** 默认不会。请在设置中开启“Windows 登录后自动启动”，并将程序保存在固定目录。

**助手提示没有连接 / 无法读取？** 确认使用同一浏览器登录、刷新平台页，确认助手版本与程序配套，然后在便签中重新连接扩展 ID。`DDLNotesSync.exe` 必须与主程序放在一起。

**课程作业没导入？** 先检查上面的平台和学期范围，以及任务是否已完成、是否已超期 48 小时。保留完整错误提示，到 [Issues](https://github.com/Skylar-Jiang/ddl-notes/issues) 反馈；请勿提交 Cookie、Token、完整任务备份或含个人信息的截图。

**能用在 macOS / Linux 上吗？** 当前只面向 Windows，窗口、托盘、自启动和打包均使用 Windows 实现，其他平台未验证。

## 从源码运行与开发

需要 Git、Windows 上的标准 Python **3.11+**（含 Tkinter，已实测 3.12.6）。在 PowerShell 中运行：

```powershell
git clone https://github.com/Skylar-Jiang/ddl-notes.git
cd ddl-notes
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

无需激活虚拟环境。仅预览界面可运行 `run.py --demo`，使用隔离的示例数据。需要另一个独立数据目录时可使用 `--data-dir <绝对目录>`。这两个参数同样支持打包后的 exe。

从源码使用课程同步时，还需先按下文构建 `dist\DDLNotesSync.exe`，再在便签中连接浏览器助手。

### 测试与构建

构建额外需要 Node.js（只用于浏览器读取器测试；用户运行程序无需 Node）。源码仓库不包含 exe 或 `dist`，构建脚本会生成它们。

```powershell
# Python 测试：包含实际 Tk 窗口，需要可用的 Windows 桌面会话
.\.venv\Scripts\python.exe -m unittest discover -s tests -v

# 浏览器读取器模拟测试
node --test tests/browser_readers.test.cjs

# 安装构建依赖、执行测试并生成 Windows 程序与压缩包
powershell -ExecutionPolicy Bypass -File .\build.ps1 -InstallDependencies
```

构建结果位于 `dist`：主程序、同步桥接、浏览器助手及说明文档。Node 不在 PATH 时，给构建脚本传 `-NodePath <node.exe 路径>`；加 `-OneDir` 可生成目录版，运行时需保留整个目录。

主要代码位于 `ddl_notes/`，平台读取器位于 `browser-helper/`，测试位于 `tests/`。实现使用 Python / Tkinter、pystray 和 Pillow，打包使用 PyInstaller。验证记录和尚未覆盖的场景见 [TESTING.md](TESTING.md)。
